# AI Document Assistant

A small learning project exploring how AI can be used to analyze business documents and return structured information.

## 🎯 Goal

The goal is to build a simple workflow that can:

1. Read a text document
2. Extract relevant information
3. Send the content to an AI model
4. Return the result in a structured format
5. Make document analysis easier to automate

## 🧩 Example Workflow

Document → Text Extraction → AI Analysis → Structured Output

## 📄 Example Information

The assistant should be able to identify information such as:

* Company
* Project
* Budget
* Deadline
* Risks
* Summary

## 🛠️ Technologies

Currently planned:

* C++
* REST API
* JSON
* Large Language Models
* Git & GitHub

## 🚧 Project Status

Work in progress.

This project is being developed step by step as a practical introduction to AI integration and document automation
